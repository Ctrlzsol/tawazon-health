# توازن — Tawazon Health

منصة صحية عربية ثابتة وسريعة، تضم 32 مقالاً موثقاً في ستة مسارات: التغذية، الوزن، الحركة، النوم، الهضم، والمكملات.

## النشر

المجلد جاهز للنشر مباشرة على Vercel أو GitHub Pages دون خطوة بناء.

قبل ربط نطاق نهائي، استبدل `https://tawazon-health.vercel.app` في `build_site.mjs` بالنطاق الحقيقي ثم شغّل:

```bash
node build_site.mjs
```

## AdSense

كود الناشر `ca-pub-1304668609520202` مضمّن في جميع الصفحات، وملف `ads.txt` موجود في الجذر. ظهور الإعلانات يتطلب إضافة النطاق إلى AdSense وموافقة Google.

## التحرير

المحتوى تثقيفي ولا يستبدل الرعاية الطبية. راجع `editorial.html` و`disclaimer.html` قبل النشر النهائي.

للنشر المنتظم: أضف المقال إلى `content.json` بالمصادر والتصنيف وتاريخ المراجعة، ثم شغّل `node build_site.mjs`. سيعيد المولد إنشاء المقالات وصفحات المسارات والمكتبة وخريطة الموقع وخلاصة RSS.
